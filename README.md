# 数据管理库

一个轻量、中文界面的本地资料管理工具。把散落的数据文件、PPT 和图片，整理到「项目 → 分类 → 文件」的多层目录中，让研究资料、工作素材与阶段成果井然有序。

使用 Python 标准库和 SQLite，无需数据库服务、Node.js 或第三方 Python 依赖。浏览器负责操作，文件和索引保存在自己的电脑中。

## 快速开始

安装 Python 3.10 或更新版本，下载本仓库后运行：

```bash
python app.py
```

打开 http://127.0.0.1:8765 。Windows 用户也可以双击 `start.bat`，然后在浏览器打开该地址。关闭终端或按 Ctrl+C 停止服务。

端口被占用时：`python app.py --port 8766`。

## 功能

- **多层目录**：新建项目、分类和子分类，父目录汇总显示后代目录中的文件。
- **批量上传**：选择多个文件或拖入文件列表，单文件最大 50 MB。
- **快速检索**：按文件名、标签搜索，按数据 / PPT / 图片 / 其他类型筛选。
- **资料整理**：修改标签、移动文件、下载文件、删除文件、删除空目录。
- **图片预览**：PNG、JPEG、GIF、WebP。
- **数据预览**：CSV / TSV 前 100 行、40 列；支持 UTF-8 和 GB18030 文本。
- **PPTX 预览**：提取前 100 页的文字，不还原原始排版、图表、动画或讲者备注。
- **文本预览**：TXT、Markdown、JSON，最多显示 30,000 字符。
- **本地持久化**：刷新页面和重启服务后仍保留文件及分类。

XLSX、XLS、旧版 PPT、PDF、SVG 等其他文件可上传、分类与下载，目前没有内置内容预览。此版本不包含数据清洗、统计计算或 PPT 编辑功能。

## 使用方法

1. 点击侧栏「＋」，创建一个项目目录。
2. 选中项目，继续点击「＋」创建数据、PPT、图片等分类。
3. 选中目标目录，上传文件。
4. 点击文件名称预览，点击「整理」调整目录和标签。
5. 使用搜索栏或类型按钮快速定位资料。

「全部文件」或「未分类」视图中上传的文件进入未分类；可以随后移动。

## 数据与备份

默认数据保存在 `data/`，其中 `library.sqlite` 保存目录和文件信息，`files/` 保存原始文件。备份时先停止服务，再复制整个 `data/` 目录；恢复时同样先停止服务，再放回完整目录。

可以通过环境变量 `DATA_LIBRARY_HOME` 指定其他存储目录。源码仓库忽略运行数据，上传到 GitHub 的源码不会自动包含你的资料。

服务只监听 `127.0.0.1`，适用于个人本地使用；没有账号系统，不应改为公网服务直接部署。删除文件不可撤销。
